# myshop

⚡ Интернет-магазин электроники на Django, разработанный в процессе обучения.
Реализует ключевые механики e-commerce: каталог товаров, категории, корзину и оформление заказов. Проект демонстрирует понимание backend-логики, работы с базой данных и построения пользовательского интерфейса.
---

## 🚀 Функционал

* 📦 Каталог товаров
* 🗂️ Категории товаров
* 🔍 Просмотр детальной страницы товара
* 🛒 Добавление товаров в корзину
* ➕ Изменение количества товаров
* ❌ Удаление товаров из корзины
* 📄 Оформление заказа
* 🧾 Хранение заказов в базе данных

## 🏗️ Архитектура проекта

Проект построен на Django и разделён на отдельные приложения, каждое из которых отвечает за свою часть логики интернет-магазина.

* `shop/` — основное приложение: товары, категории, страницы каталога и товара

* `cart/` — управление корзиной (добавление, удаление, изменение количества)

* `orders/` — оформление и сохранение заказов

* `shop/templates/` — основные HTML-шаблоны и базовый layout

* `cart/templates/` — страницы корзины

* `orders/templates/` — оформление заказа

* `static/` — стили и изображения интерфейса

* `media/` — загружаемые изображения товаров

* `myshop/` — конфигурация проекта (settings, urls и т.д.)

Архитектура построена по принципу разделения ответственности, что упрощает поддержку и дальнейшее развитие проекта.

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
venv\Scripts\activate   # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Применить миграции

```bash
python manage.py migrate
```

### 5. Запустить сервер

```bash
python manage.py runserver
```

---

## 🔑 Админ-панель

Создать суперпользователя:

```bash
python manage.py createsuperuser
```

Админка доступна по адресу:

```
http://127.0.0.1:8000/admin/
```
